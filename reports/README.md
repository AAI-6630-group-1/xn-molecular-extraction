# Reports

Individual reports go in `reports/<handle>/` (1.3 now, and later the 2.3 documentation, 3.1 and 3.3), as we agreed on 2026-10-06 (#73). Group write-ups such as the 1.5 combined report and the 2.4 pipeline report go in their own folders here. Keep a report's figure scripts beside it.

PDFs are ignored by git by default so papers do not get committed by accident. Use `git add -f` for a report PDF you really want here.
