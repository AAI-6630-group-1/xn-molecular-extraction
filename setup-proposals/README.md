# Setup proposals

Each person's XN 1.1 setup proposal, in a folder named after their GitHub handle: `setup-proposals/<handle>/`. We agreed on 2026-10-06 (#73) to share files here rather than in Slack.

PDFs are ignored by git by default so papers don't get committed by accident. To commit your own proposal as a PDF, use `git add -f setup-proposals/<handle>/<file>.pdf`.
