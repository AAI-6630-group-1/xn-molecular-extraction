# Pipeline (Phase 2)

The extraction pipeline for XN tasks 2.2 to 2.4: PDF in, SMILES out. The stages and who owns each module get decided in task 2.1.

A starting point from the sponsor paper: PDF parsing and figure extraction, molecule detection with a molecule/non-molecule filter, per-molecule cropping, structure recognition (OCSR), SMILES canonicalization, and scoring against ground truth.
